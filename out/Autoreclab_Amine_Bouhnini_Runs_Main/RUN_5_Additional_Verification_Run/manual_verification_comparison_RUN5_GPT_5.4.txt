Manual Verification Comparison - RUN5 GPT-5.4 Docker
==============================================================

Purpose
-------
This file compares the values reported in the AutoRecLab final report with the
values produced by manually executing the generated runfile.py in the same Docker
environment. The goal is to verify that the reported metrics were traceable to
actual code execution and were not only generated in the LLM text summary.

Source files
------------
AutoRecLab report log: RUN5_GPT_5.4_Powershell.txt
Manual execution log: manual_run_output.txt

Manual execution command
------------------------
uv run python runfile.py 2>&1 | tee manual_run_output.txt

Experimental protocol reported by AutoRecLab
--------------------------------------------
- Dataset: MovieLens100K u.data
- Split: one fixed random 80/20 train/test split using seed 2024
- Model: LensKit ImplicitMF
- Hyperparameters: features=20, iterations=15, reg=0.1, weight=40, method='cg'
- Seeds: 1, 7, 21, 42, 84, 126, 168, 210, 252, 294
- Metrics: Recall@10 and NDCG@10

Conclusion
----------
The manual runfile execution reproduced the same per-seed Recall@10 and NDCG@10
values reported by AutoRecLab. The aggregate summary values also match; the only
difference is that AutoRecLab rounded the CV percentages in the final text, while
the manual output printed them with higher precision. This supports the conclusion
that the reported results were traceable to executable Python code, not hallucinated.
