I ran the seed-sensitivity experiment exactly as described in the provided code:

- Loaded MovieLens100K from `u.data`
- Did a single random 80/20 train/test split using seed `2024`
- Trained LensKit `ImplicitMF` 10 times with identical hyperparameters and different training seeds:
  `1, 7, 21, 42, 84, 126, 168, 210, 252, 294`
- Model settings were:
  - `features=20`
  - `iterations=15`
  - `reg=0.1`
  - `weight=40`
  - `method='cg'`
- Evaluated top-10 recommendation quality with `Recall@10` and `NDCG@10`

What changed across runs was only the model RNG seed.

The per-seed results were:

- seed 1: Recall@10 = 0.1754, NDCG@10 = 0.2401
- seed 7: Recall@10 = 0.1776, NDCG@10 = 0.2447
- seed 21: Recall@10 = 0.1752, NDCG@10 = 0.2422
- seed 42: Recall@10 = 0.1834, NDCG@10 = 0.2467
- seed 84: Recall@10 = 0.1774, NDCG@10 = 0.2459
- seed 126: Recall@10 = 0.1751, NDCG@10 = 0.2433
- seed 168: Recall@10 = 0.1784, NDCG@10 = 0.2437
- seed 210: Recall@10 = 0.1775, NDCG@10 = 0.2450
- seed 252: Recall@10 = 0.1726, NDCG@10 = 0.2376
- seed 294: Recall@10 = 0.1735, NDCG@10 = 0.2375

Overall variation across seeds:

- Recall@10
  - mean: 0.176625
  - std: 0.002887
  - min: 0.172618
  - max: 0.183415
  - coefficient of variation: 1.63%

- NDCG@10
  - mean: 0.242677
  - std: 0.003103
  - min: 0.237509
  - max: 0.246690
  - coefficient of variation: 1.28%

A few takeaways:

- There is measurable seed-to-seed variation, so the random seed does affect results.
- But in this setup, the effect is modest rather than dramatic.
- The best vs. worst run differed by about:
  - `0.0108` absolute Recall@10
  - `0.0092` absolute NDCG@10
- Relative variability was low: about 1.3–1.6% by coefficient of variation.

So, based on this experiment, reporting seeds does seem worthwhile, but mainly for reproducibility and fairness rather than because seeds completely change the conclusions. The experiment’s own summary concluded:

“Seed sensitivity appears modest for this setup, but reporting seeds is still good practice.”

One important limitation: this used only one train/test split. So the results quantify variation from training seed only under that fixed split, not variability across different data splits.
