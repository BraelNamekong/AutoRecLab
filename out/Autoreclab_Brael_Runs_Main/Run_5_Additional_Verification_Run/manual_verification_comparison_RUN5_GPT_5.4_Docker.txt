Manual Verification Comparison - RUN5 GPT-5.4 Docker
==============================================================

Purpose
-------
This file compares the values reported in the AutoRecLab final report with the
values produced by manually executing the generated runfile.py in the same Docker
environment. The goal is to verify that the reported metrics were traceable to
actual code execution and were not only generated in the LLM text summary.

Source files
------------
AutoRecLab report log: RUN5_gpt_5.4_powershell.txt (final text summary)
AutoRecLab raw execution output (per-seed): manual_run_output.txt
Manual execution log: Manuall_execution_RUN5_gpt-5.4_Docker.txt

Manual execution command
------------------------
uv run python runfile.py 2>&1 | tee manual_run_output.txt

Experimental protocol reported by AutoRecLab
--------------------------------------------
- Dataset: MovieLens100K u.data
- Split: one fixed user-wise 80/20 train/test split using split seed 2024
- Relevance definition: rating >= 4 treated as an implicit positive interaction
- Model: LensKit ImplicitMF
- Hyperparameters: features=30, iterations=20, reg=0.01, weight=40
- Seeds: 1, 7, 13, 21, 42, 87, 123, 256, 512, 1024
- Metrics: Recall@10 and NDCG@10
- Evaluated data: 43,929 train interactions, 11,392 test interactions, 942 evaluation users

Conclusion
----------
All 10 per-seed values for
both NDCG@10 and Recall@10 match the manual execution exactly (AutoRecLab's console
output rounds to 4 decimal places, while the manual per-seed table prints 6 decimal
places, but the underlying numbers agree). The aggregate summary statistics (mean,
std, min, max, range, and CV for both metrics) also match. This supports the
conclusion that the reported results were traceable to executable Python code, not
hallucinated.
